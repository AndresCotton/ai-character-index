# data/

The canonical machine-readable data the site renders from. **The site contains no data of its own; Notion is never read directly by the site.** Changes arrive here only via reviewed pull requests -- either opened by `engine/notion-sync` or written by hand during Phase 1-2 (extracted from [`research/core-behaviour-list.md`](../research/core-behaviour-list.md), which already contains every verdict and citation for the two launch labs).

Empty until Phase 1. Planned files (full field lists in [PLAN.md §2](../PLAN.md)):

| File | One row per | Source of truth |
|---|---|---|
| `behaviours.json` | behaviour (the 12 + parked) | Notion "Behaviours to track" (hand-extracted until the Behaviours DB exists) |
| `labs.json` | lab | hand-maintained (changes rarely) |
| `coverage.json` | behaviour × lab verdict, with citations | Notion Coverage DB (Phase 3; hand-extracted before that) |
| `evals.json` | eval, with rubric quality scores | Notion "Evals by Behaviour" DB |
| `meta.json` | -- (site-wide metadata) | generated by sync |

One file here is deliberately **not** index data: `reader-test-coverage.json`, the ledger behind the [reader test bench](../site/spec-reader-test/README.md). It holds an external reviewer's behaviour set -- definitions plus one coverage record per behaviour × lab, in the same record shape as `coverage.json` so a record can be lifted from a sweep unchanged -- and feeds only `site/spec-reader-test/`. Nothing in it is an index verdict, and nothing in it reaches `behaviours.json`, `coverage.json` or the published reader. Its current contents come from the stage-4 sweeps in [`behaviours-for-adria/`](../behaviours-for-adria/README.md).

`schema/` holds the JSON Schemas; CI validates every PR against them. Rules worth encoding from day one: no coverage verdict without at least one citation (quote + spec version + date verified), no eval without a URL, no unknown behaviour IDs.

Derived views (evidence strength per cell, the gap list) are computed by the site at build time and never stored here, so they can never go stale.
